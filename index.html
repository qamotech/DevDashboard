🌐 Hosting & Custom Domain CNAME Configuration
To run this dashboard online, push `index.html` and the `apps/` folder to a GitHub repository, then enable **GitHub Pages** under repository settings.
To bind a custom domain (e.g. `dashboard.qamelot.com`):
1. Create a file named CNAME (no file extension) in the root of your GitHub repository.
2. Type your domain in it (e.g. dashboard.qamelot.com) and save.
3. Configure your domain registrar's DNS records: point a CNAME record to yourusername.github.io.
